# Figures

This directory contains both the final PNGs generated by the recorded experiment and editable SVG summaries.

- `architecture_72d_zh_fusion.png` / `.svg`: 72 numeric input features, AE latent vector Z (32-D), k-NN graph (k=10), GCN hidden embedding H (16-D), fusion [Z || H] (48-D), Random Forest prediction.
- `final_zh_roc_curve.png`: ROC curve for the final [Z || H] fusion run (reported ROC-AUC 0.998172).
- `final_zh_precision_recall_curve.png`: precision–recall curve for the final [Z || H] fusion run (reported average precision 0.992614).
- `final_zh_confusion_matrix.png` / `.svg`: final test confusion matrix (TN=443,100; FP=11,125; FN=1,288; TP=110,023).
- `model_comparison.png` / `.svg`: comparison of recorded AE+RF and AE–GNN–RF results.

The PNG files are the stored figures from the project workspace. The SVG diagrams are summary visualizations of the reported architecture, confusion counts, and selected metrics; they are not replacements for newly rerun experiments.
