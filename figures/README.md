# Figures

- `architecture_72d_zh_fusion.svg`: schematic of the reported 72 → 32 → 16 → 48-dimensional pipeline.
- `final_zh_confusion_matrix.svg`: final [Z || H] test confusion matrix using the reported counts.
- `model_comparison.svg`: comparison of the reported AE+RF baseline and [Z || H] fusion metrics.

The SVGs in this repository are reproducible, text-based diagrams. The raw ROC/PR plotted coordinates were not included in the repository package's text sources, so this repository reports ROC-AUC and average precision numerically instead of recreating those curves from invented points.
